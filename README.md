# 🖥️ C# Projeleri 

Bu repository, **C#** programlama dili ile geliştirilmiş **uygulamalar**, **kütüphaneler** ve **örnek kod parçalarını** içermektedir.
Amacımız, hem **yeni başlayanlara** hem de **deneyimli geliştiricilere** ilham verecek, temiz ve modern çözümler sunmak.

---

## 🛠 Kullanılan Teknolojiler

| Kategori       | Teknoloji / Araçlar           |
| -------------- | ----------------------------- |
| **Dil**        | C# (.NET 6, .NET 7, .NET 8)   |
| **Framework**  | ASP.NET Core, WinForms, WPF   |
| **Veritabanı** | SQL Server, SQLite            |
| **Araçlar**    | Visual Studio, VS Code |

---

## 📦 İçerik

* **💻 Konsol Uygulamaları** – Temel algoritmalar, veri yapıları
* **🌐 Web API Projeleri** – RESTful servisler, JWT Authentication
* **🖥 Masaüstü Uygulamaları** – WinForms & WPF ile masaüstü çözümler
* **📊 Veritabanı İşlemleri** – Entity Framework Core ile CRUD
* **🧩 Design Pattern Örnekleri** – Singleton, Repository, Factory vb.

---

## 🎯 Özellikler

✔ **Temiz Kod** – SOLID prensiplerine uygun geliştirme
✔ **Yorum Satırları** – Anlaşılır ve eğitim amaçlı örnekler
✔ **Gerçek Dünya Senaryoları** – Sadece “Hello World” değil, işlevsel çözümler
✔ **Çok Katmanlı Yapı** – Daha düzenli ve ölçeklenebilir kod
